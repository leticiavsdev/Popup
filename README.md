# 🚀 Pop-up / Modal Box Interativo (HTML, CSS & JavaScript)

> Uma caixa de diálogo (pop-up) elegante e animada, acionada por eventos de clique, desenvolvida com tecnologias web fundamentais.

## 📌 Sobre o Projeto
Este projeto consiste na criação de um **Pop-up / Modal Box** moderno com transições suaves. A aplicação exibe um botão principal na tela; ao ser acionado, uma janela de sucesso (com ícone de verificação, título, mensagem descritiva e botão de confirmação) surge do topo da tela com um efeito de escala e transição fluido. O projeto foi desenvolvido com foco em interatividade básica e estilização limpa.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica da página, botão de gatilho, elementos do modal e inclusão de ícones.
- **CSS3:** Estilização avançada, Flexbox para centralização, propriedades de posicionamento (`absolute`), sombras (`box-shadow`), bordas arredondadas e **transições CSS** (`transition`) para animações fluidas.
- **JavaScript (Vanilla):** Manipulação de DOM (`classList.add` e `classList.remove`) para controlar a visibilidade e o comportamento dinâmico do pop-up ao interagir com os botões.
